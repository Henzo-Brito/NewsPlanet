# 🌐 NewsPlanet

> **As principais notícias de tecnologia em um só lugar.**

O **NewsPlanet** é uma plataforma desenvolvida para reunir e apresentar as principais notícias e novidades do mundo da tecnologia de forma simples, organizada e acessível.

## 🚀 Acesse o projeto

🔗 **[Visite o NewsPlanet](https://henzo-brito.github.io/NewsPlanet/)**

---

## ✨ Funcionalidades

- 📰 Visualização de notícias de tecnologia
- 🔎 Navegação simples e intuitiva
- 📱 Interface responsiva
- ⚡ Experiência rápida e objetiva
- 🌐 Notícias organizadas para facilitar a navegação

---

## 🛠️ Tecnologias

O projeto foi desenvolvido utilizando:

- **HTML5** — estrutura da aplicação
- **CSS3** — estilização e responsividade
- **JavaScript** — interações e funcionalidades
- **Git & GitHub** — versionamento e hospedagem

---

## 🎯 Objetivo

O objetivo do **NewsPlanet** é proporcionar uma experiência simples para quem deseja acompanhar as novidades do universo tecnológico, reunindo informações de maneira organizada e visualmente agradável.
